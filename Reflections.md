## Reflections about ARIA

### 1. Accessibility enhancements implementation and enhancements

The ARIA tools that can be applied to the html file would be:
    
    1. Color Contrast: The color contrast between the different elements would should be easy for differently abled people to see. The contrast between the colors can be seen using different tools available on the web. The contrast ratio between the colors should be more than 4.5:1 for it to be considered a good accessible webpage. I would use the WebAIM website since it is easier to navigate.
    2. Alt for images: The alt attribute should be added to any of the images so it is easy for the screenreaders to describe what the image used in the webpage is about and looks like. The description should be concise and to the point for it to be easier to absorb.
    3. Links: The links used in the webpage should be clearly identified and not blend into the contents of the webpage. Clearly marked links make it easy for the user to spot and not miss.
    4. Placeholders: Placeholders should be used to give the user an idea of what the input is being asked of them.
    5. Labels: Labels make it easier for the screenreader to read and the other users to see categorize and see what is avalaible and needed.
